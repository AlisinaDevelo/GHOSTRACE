## Goal
Define support windows, security fixes, schema readers, export tools, macOS versions, adapters, algorithms, migration utilities, and end-of-life communication for local evidence owners.

## Acceptance criteria
- [ ] Every public surface has introduction, deprecation, removal, migration, rollback, and artifact-retention rules.
- [ ] Emergency security removal is distinguished from planned deprecation and includes affected-data guidance.
- [ ] Users can remain on a supported reader or export their evidence without enabling new collectors or cloud services.

## Context
Local journals may outlive the binary version that created them.
