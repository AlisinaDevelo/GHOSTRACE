## Goal
Test whether users can distinguish direct evidence, context, inference, conflict, unknowns, disabled sources, policy denial, and collection gaps in realistic investigation tasks.

## Acceptance criteria
- [ ] A reviewed protocol defines recruitment, consent, synthetic data, tasks, comprehension measures, accessibility, analysis, and withdrawal handling.
- [ ] No participant journal or ambient activity is collected; study artifacts use the public synthetic corpus.
- [ ] Results identify misleading language or UI patterns and create traceable remediation issues before publication.

## Context
First-class gaps only help when users can perceive and correctly interpret them.

Planned in the 2026–2031 GHOSTRACE program. Completion requires the acceptance evidence above; issue closure alone is not evidence.
