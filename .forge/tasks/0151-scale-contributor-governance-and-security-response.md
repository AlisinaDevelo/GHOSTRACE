## Goal
Define maintainership, review authority, release custody, conflict handling, adapter policy, vulnerability intake, embargo, disclosure, and succession before ecosystem growth.

## Acceptance criteria
- [ ] A public governance document names roles, decision records, quorum or solo-maintainer fallback, recusal, and transfer procedures.
- [ ] Security response defines supported versions, contact, encryption, triage, coordinated disclosure, CVE handling, downstream adapter notice, and postmortem rules.
- [ ] Release and signing authority follows least privilege, recovery, audit, and two-person controls where participation permits.

## Context
Technical controls need a durable human authority and incident model.

## Notes
Planned in the 2026–2031 GHOSTRACE program. Completion requires the acceptance evidence above; issue closure alone is not evidence.
