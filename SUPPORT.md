# Support

Start with the [README](README.md) and the [documentation index](README.md#documentation).
The fixture-only demo is the supported path in the current developer headstart.

For a reproducible problem, open the [bug report form](https://github.com/AlisinaDevelo/GHOSTRACE/issues/new?template=bug_report.yml).
For a narrowly scoped idea, use the [proposal form](https://github.com/AlisinaDevelo/GHOSTRACE/issues/new?template=proposal.yml).

When filing an issue:

- include the commit or release, operating system, Rust version, command, and
  synthetic reproduction;
- include the exact error text after removing paths and identifiers;
- describe expected and actual behavior;
- do not attach journals, exports, screenshots, browser data, file contents, or
  secrets.

Security reports do not belong in public issues. Use the process in
[SECURITY.md](SECURITY.md).

Questions about an unimplemented collector should be framed as a proposal. The
roadmap is directional, and a capability remains unavailable until its consent,
privacy, completeness, and recovery gates pass.
